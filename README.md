📍 México &nbsp;|&nbsp; 🎓 Ingeniería en Desarrollo y Gestión de Software

Soy **Ingeniero en Desarrollo y Gestión de Software** especializado en la construcción de aplicaciones web y backend escalables, mantenibles y de alto rendimiento.
