## 📁 Proyectos Destacados

### 1. ⚡ [Servicios-Back](https://github.com/Osvaldo1232/Servicios-Back)
> **Stack:** Java 21 | Spring Boot | Spring Security (JWT) | JPA / MySQL | Swagger
* **Descripción:** Robustas APIs RESTful diseñadas como motor principal de servicios backend para aplicaciones empresariales.
* **Aspectos Técnicos:** Implementación de seguridad y control de acceso mediante tokens JWT sin estado, mapeo relacional con JPA/Hibernate, módulo automatizado para generación de reportes en PDF y documentación interactiva de endpoints con Swagger.

### 2. 🅰️ [Front](https://github.com/Osvaldo1232/Front)
> **Stack:** Angular | TypeScript | RxJS | SCSS
* **Descripción:** Aplicación web cliente integradora diseñada para interactuar con arquitecturas distribuídas de microservicios backend.
* **Aspectos Técnicos:** Modularización mediante *Domain-Driven Architecture*, componentes reactivos, manejo centralizado de sesiones de usuario e integración fluida de servicios HTTP.

### 3. 📚 [Servicios-Biblioteca](https://github.com/Osvaldo1232/Servicios-Biblioteca) + [Front-End-Biblioteca](https://github.com/Osvaldo1232/Front-End-Biblioteca)
> **Stack Full-Stack:** Java (Spring Boot) | Angular | TypeScript | MySQL | SCSS
* **Descripción:** Sistema Full-Stack desacoplado para la gestión integral de bibliotecas, préstamos e inventario bibliográfico.
* **Aspectos Técnicos:** Arquitectura cliente-servidor con separación total de responsabilidades, gestión de estado reactivo en cliente con RxJS y backend relacional optimizado para operaciones CRUD masivas.

### 4. 🎬 [Prueba-Tecnica-Angular](https://github.com/Osvaldo1232/Prueba-Tecnica-Angular)
> **Stack:** Angular | TypeScript | RxJS | OMDb Public API
* **Descripción:** Solución frontend orientada a evaluación técnica para el consumo dinámico de datos cinematográficos.
* **Aspectos Técnicos:** Consumo directo de la API pública OMDb, implementación de formularios reactivos con validaciones avanzadas, manejo explícito de desuscripciones para prevenir fugas de memoria y optimización de renderizado.

### 5. ⚡ [Harry-Potter](https://github.com/Osvaldo1232/Harry-Potter)
> **Stack:** JavaScript Vanilla (ES6+) | HTML5 | CSS3 | REST API (Fetch)
* **Descripción:** Aplicación web interactiva para la exploración del universo de Harry Potter consumiendo APIs públicas.
* **Aspectos Técnicos:** Arquitectura basada en módulos de JavaScript puro sin frameworks externos, manipulación eficiente del DOM, filtrado dinámico en tiempo real y flujo de asincronía limpio con `async/await`.
